# 수집과 복구

기본 진입점은 `python3 SKILL_DIR/scripts/collect_transcript.py INPUT`이다. 모든 옵션은 같은 진입점에 붙인다. 모델·OCR 설치 방법은 [설치 안내](install.md)에 있다.

- `--language ko`/`en`: 언어 선택. 지역 표기까지 명시하면 정확히 일치하는 트랙을 요구한다. 원어가 모호하거나 여러 내장 언어가 있으면 `needs_language`의 선택지를 사용자에게 확인한다. 자동 번역을 원문 자막으로 저장하지 않는다.
- `--mode auto|captions|stt|ocr`: 자동 경로, 기존 자막만, 음성 전사, 화면 OCR. `auto`는 로컬 영상에 음성이 있으면 STT를 선호하므로 음성 대신 화면 글자를 원하면 `ocr`를 명시한다.
- `--ocr-region full|bottom|x,y,w,h`, `--ocr-fps 0.5~10`: OCR 영역과 표본 빈도. 기본 전체 화면 2fps, 짧은 문구는 표본 사이에서 누락될 수 있다.
- `--output-dir PATH`: MD 위치 변경. 기존 MD는 자동 덮어쓰지 않는다. 내용/출처가 다른 판본은 다른 파일명이 될 수 있다. 한 추출 결과는 MD 한 파일이다.
- `--refresh`: 다시 수집. `--resume`: 보존된 저장 단계/검증 재개. 캐시 재사용과 재개에도 다른 자막 경로를 새로 조회한다. 로컬 미디어는 같은 입력을 다시 호출하면 체크포인트를 사용한다.
- `--verify RECEIPT`: 삭제 후 보존된 MD 해시·기존 대조 기록을 점검하는 오프라인 명령이다. 새 API 대조나 삭제한 원본 재조회가 아니다.

## 접근과 요청 제한

`needs_browser`/`needs_login`이면 현재 에이전트가 지원하는 브라우저 도구로 정상 시청 여부와 원어 자막을 확인한다. 로딩 중인 패널을 자막 없음으로 판단하지 않는다. `429`는 반환된 대기 시각을 따르고 동일 요청을 반복하지 않는다. 접근 거부·권한 거부·계정 검증은 우회하지 않는다. 공개 자막 API가 실패했다는 이유만으로 STT를 실행하지 않는다.

브라우저가 전문 내보내기를 실제 지원하면 반환된 파일 경로를 `--browser-export FILE`로 전달한다. 도구에 없는 기능을 가정하지 않는다. 원시 자막을 모델이 재작성하지 않는다. 사용자가 제공한 SRT/VTT/JSON3/JSON/TXT는 `--import-file FILE`로 읽으며 제공 파일을 삭제하지 않는다. 제공 파일 보존 성공과 영상 전체 자막 여부는 구분하고 가능한 유튜브 사본과 대조한다.

DOM을 사용해야 하면 현재 도구로 처음·마지막 경계와 전문 로딩을 실제 확인한 뒤 원문을 그대로 파일로 내보낸다. 가져오기 JSON 형태는 `{"video_id":"VIDEO_ID","language":"ko","segments":[{"start":1.0,"duration":null,"text":"화면 원문 그대로"}]}`이다. 전문 여부가 미확인인 결과를 완전한 대본으로 보고하지 않는다.

정상 시청 권한이 확인됐고 브라우저 내보내기가 불가능할 때만 현재 사용자의 브라우저 인증 경로를 명시한다:

```sh
python3 SKILL_DIR/scripts/collect_transcript.py URL --browser chrome --browser-access-confirmed
```

특정 프로필이 필요하면 확인한 값으로 `--browser-profile PROFILE`을 추가한다. 쿠키를 공유·내보내거나 다른 사람의 계정을 배포하지 않는다. 인증된 수집도 다른 자막 경로 대조 대상이며, 다른 경로가 로그인 영상에 접근하지 못하면 MD는 유지하되 `partial`로 알린다.

## 정리와 실패 상태

성공한 영상의 임시 데이터는 자동 정리한다. 로컬 사용자 원본은 유지한다. 실패/중단 자료는 재개를 위해 남을 수 있으므로 다음 같은 입력 실행으로 복구한다. 다른 작업·다른 사용자의 자료를 일괄 삭제하지 않는다. `cleanup_pending`은 경로/권한 문제를 해소하고 같은 입력으로 재시도한다. 모델·영수증·중복 방지 색인·작업 잠금·요청 대기 상태는 재사용 자료다.

`caption_audit.status: passed`는 동일 유튜브 자막의 전체 일치이며 영상 음성과의 일치를 뜻하지 않는다. STT 인명·숫자·전문용어, OCR 인식과 표본 사이 짧은 문구는 별도 검수 범위다. 잠금·낮은 우선순위·CPU 스레드 제한은 부하를 줄이는 설정이며 다른 작업의 영향이 0이라는 의미는 아니다.
